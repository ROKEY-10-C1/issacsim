# 정상 공정 시나리오 — 타이어 조립 셀

전체 흐름: **차량 이송 → 타이어 공급 → 품질 검사 → 허브 인식 → 파지 → 회전각 정렬 → 조립 → 볼트 체결 → 최종 검사 → 차량 배출**

| 단계 | 주체 | 완료 신호 (→ 받는 쪽) |
|---|---|---|
| 1. 차량 이송 | AMR, 비전 카메라 | 차량 이송 완료 → 중앙 제어 |
| 2. 타이어 공급 | 공급 장치, 타이어 공급 라인 | 타이어 공급 완료 → 중앙 제어 |
| 3. 품질 검사 | 레일 위 카메라 (임시) | 검사 결과 → 중앙 제어 |
| 4. 허브 위치·각도 인식 | 타이어 장착 로봇, 핸드아이 카메라 | 허브 목표 좌표 저장 |
| 5. 타이어 파지 | 타이어 장착 로봇, 타이어 그리퍼 | — |
| 6. 회전각 정렬 | 핸드아이 카메라, 그리퍼 하부 롤러 | — |
| 7. 타이어 조립 | 타이어 장착 로봇 | 조립 완료 → 볼트 체결 로봇 |
| 8. 볼트 체결 | 볼트 체결 로봇 | 체결 완료 → 타이어 장착 로봇 |
| 9. 최종 검사 | 타이어 장착 로봇, 검사 | 최종 검사 결과 → 중앙 제어 |
| 10. 차량 배출 | 중앙 제어, AMR | 배출 명령 → AMR |

---

## 1단계. 차량 이송
1. AMR에 타이어가 장착되지 않은 차량을 적재한다.
   - 비전 카메라로 타이어와 휠의 이미지를 취득한다.
2. AMR이 차량을 결합구역으로 이송한다.
3. AMR이 지정된 작업 위치에 정차하고 차량 위치를 유지한다.
4. 중앙 제어 시스템에 **차량 이송 완료** 신호를 전달한다.

## 2단계. 타이어 공급
1. 타이어 공급 장치가 타이어를 한 개씩 타이어 공급 라인로 배출한다.
2. 타이어 공급 라인가 타이어를 지정된 작업 위치까지 이송한다.
3. 타이어가 타이어 수용대에 도착한다.
4. **타이어 공급 완료** 신호를 전달한다.

## 3단계. 타이어 품질 검사
> ❓ **결정 필요:** 어느 카메라가 맡을지 정해야 합니다. 일단은 레일 위 카메라가 앞면만 검사합니다.

1. 타이어와 휠의 외관 및 결함 여부를 검사한다.
2. 품질 검사 결과를 중앙 제어 시스템에 전달한다.

## 4단계. 허브 위치 및 각도 인식
1. 타이어 장착 로봇이 차량의 휠 허브 인식 위치로 이동한다.
2. 핸드아이 카메라로 휠 허브의 이미지를 취득한다.
3. 휠 허브의 중심점과 체결홀 패턴을 인식한다.
4. 휠 허브의 위치, 자세, 회전각을 계산한다.
5. 카메라 좌표계에서 로봇 기준 좌표계로 변환해 허브의 **장착 목표 좌표**를 저장한다.

## 5단계. 타이어 파지
1. 타이어 장착 로봇이 타이어 수용대로 이동한다.
2. 타이어 그리퍼의 **하부 지지 롤러**를 타이어 하단에 위치시킨다.
3. **상부 클램프**를 작동시켜 타이어를 고정한다.
4. 타이어를 들어 올린 뒤 장착에 필요한 자세로 전환한다.

## 6단계. 타이어 회전각 정렬
1. 핸드아이 카메라로 휠의 체결홀 패턴을 인식한다.
2. 휠의 현재 회전각을 계산한다.
3. 4단계에서 저장한 허브 회전각과 비교한다.
4. 두 회전각의 차이를 계산한다.
5. 그리퍼의 하부 지지 롤러를 구동해 타이어를 회전시킨다.
6. 휠과 허브의 체결 위치를 일치시킨다.

## 7단계. 타이어 조립
1. 타이어 장착 로봇이 휠 허브 전방의 접근 위치로 이동한다.
2. 휠 중심축과 허브 중심축을 정렬한다.
3. 허브 중심축 방향으로 타이어를 이동시킨다.
4. 휠을 허브에 삽입한다.
5. 볼트 체결이 끝날 때까지 타이어를 **파지한 상태로 유지**한다.
6. 볼트 체결 로봇에 **조립 완료** 신호를 전달한다.

## 8단계. 볼트 체결
1. 볼트 체결 로봇이 로봇팔 레인을 따라 작업 위치로 이동한다.
2. 휠의 볼트 체결 위치를 인식한다.
3. 너트 공급기에서 **5축 멀티 너트러너**로 너트 5개를 한 번에 집는다.
4. 너트러너 중심을 허브 축에 맞추고, 5개 소켓을 볼트 패턴(PCD 114.3 mm)에 정렬한다.
5. 5개 너트를 동시에 런다운한 뒤 동기 최종 토크로 체결한다.
6. 모든 볼트의 체결을 완료한다.
7. 타이어 장착 로봇에 **체결 완료** 신호를 전달한다.

## 9단계. 최종 검사
1. 타이어 장착 로봇이 상부 클램프를 해제한다.
2. 그리퍼를 타이어에서 분리하고 후퇴한다.
3. 휠 장착 상태와 볼트 체결 상태를 검사한다.
4. 최종 검사 결과를 중앙 제어 시스템에 전달한다.
5. 타이어 조립 및 체결 완료 상태를 기록한다.

## 10단계. 차량 배출
1. 나머지 휠 허브에 대해서도 같은 조립·체결 공정을 수행한다.
2. 차량의 모든 타이어 조립과 체결을 완료한다.
3. 타이어 장착 로봇과 볼트 체결 로봇이 대기 위치로 복귀한다.
4. 중앙 제어 시스템이 AMR에 **차량 배출** 명령을 전달한다.
5. AMR이 타이어 결합이 끝난 차체를 출고구역으로 이송한다.

## 현재 맵 구현과의 차이 (2026-11-25 기준)

시나리오와 지금 `map/wheel_cell` 라이브 물리 구현을 단계별로 비교한 표입니다.

| 단계 | 시나리오 | 현재 구현 | 상태 |
|---|---|---|---|
| 1 | AMR 이송·정차·위치 유지 | KMP1500급 AMR 주행, 리프트, 도킹 클램프 | ✅ 동작 (도킹 32.9 s) |
| 1-a | 적재 시 비전 촬영 | 없음 | ❌ |
| 2 | 공급 장치 → 컨베이어 → 수용대 | 롤러 컨베이어 물리 이송, 스토퍼 도착 감지 | ✅ 동작. 공급 장치(트럭 하역)는 제외 |
| 3 | 레일 위 카메라 품질 검사 | 불량 배출 게이트는 키프레임 시연에만 있음 | ❌ 카메라 없음 |
| 4 | 핸드아이로 허브 위치·회전각 인식 | 로봇에 D455 모델은 장착. 인식 대신 시뮬 상태값 사용 | ⚠️ 센서 미연동 |
| 5 | **로봇 그리퍼**(하부 롤러 + 상부 클램프)로 파지 | **기립 지그**(동기화된 평행 턱)가 눕혀진 타이어를 세운 뒤 **스핀들 셔틀**에 인계 | ⚠️ 파지 주체가 다름 |
| 6 | 그리퍼 하부 롤러로 회전 정렬 | 스핀들 회전 드라이브로 정렬 (오차 < 0.12°) | ⚠️ 방식이 다름, 정렬 자체는 동작 |
| 7 | **로봇이** 축 정렬 후 삽입, 체결 중 파지 유지 | **셔틀 프레스**(145 N)가 삽입. 로봇은 대기 | ⚠️ FL 3.5 mm 앞까지 진입, 안착 미완 |
| 8 | 볼트 체결 로봇이 레일 이동 후 순서대로 체결 | 크로스 순서 체결은 키프레임 시연에만 있음. 라이브에서는 대기 | ❌ 라이브 미구현 |
| 9 | 클램프 해제·후퇴·검사·기록 | 이벤트 로그(`production.sqlite3`)는 시연에만 있음 | ❌ |
| 10 | 4륜 반복 후 AMR 배출 | 배출은 키프레임 시연에만 있음 | ❌ 라이브 미구현 |

**가장 큰 차이는 5~7단계예요.** 시나리오는 타이어 장착 로봇의 그리퍼가 타이어를 들고 회전시켜 직접 끼워요. 지금 맵은 지그와 셔틀이 그 일을 하고, 로봇은 따라 움직이기만 해요. 시나리오대로 하려면 그리퍼(하부 롤러 + 상부 클램프)를 모델링하고 로봇 파지·삽입 제어를 새로 만들어야 해요. 지금의 지그·셔틀 구조를 유지할지 함께 정해야 합니다.
